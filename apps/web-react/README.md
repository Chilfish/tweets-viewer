# @tweets-viewer/web-react

Tweets Viewer 的前端应用（React Router v8，SPA-first + 静态壳）。

项目级文档与开发说明在仓库根目录：

- [`README.md`](../../README.md)
- [`docs/INDEX.md`](../../docs/INDEX.md)（文档唯一入口）

## 常用命令

在仓库根目录执行：

```bash
bun run dev:client
```

或在本目录执行：

```bash
bun dev
bun run test         # Vitest unit + stories
bun run test:visual  # Vitest vrt（视觉回归）
bun run typecheck
bun run build
```
