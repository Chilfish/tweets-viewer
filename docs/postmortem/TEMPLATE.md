# Postmortem 模板

> 复制本文件为 `00X-<短横线主题>.md`，编号顺延。保持 blameless —— 只追系统条件，不追人。

# 00X-<短横线主题>

## 摘要

一句话描述这次事故/返工。

## 影响

- 范围：影响了什么（功能/用户/构建/发布）
- 代价：返工了几轮 / 延误多久 / 引入了什么

## 时间线

- 发生了什么（按时间顺序）
- 何时暴露 / 何时被意识到

## 根因

- 直接原因：
- 系统条件（什么让它可以发生）：
- 根因归类：`流程缺失` / `工具反馈滞后` / `设计建模` / `API 契约未核实` / `脚手架阶段决策`

## 行动项

- [ ] 防止复发：具体改动（规则/工具/文档）
- [ ] 已列入 CLAUDE.md 强制规范？是否

## 复盘

- 这次踩坑沉淀了什么新规则？是否归入「高频雷区」？
