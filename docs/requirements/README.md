# 需求文档（Requirements）

**项目**: Tweets Viewer

> 功能级需求文档区。产品定位与功能优先级在此维护，与 `../Specification.md`（逻辑行为事实来源）分工：**需求说「做什么、给谁、为什么」，规格说「怎么表现」**。

## 约定

- 复杂功能需要独立 PRD / 用户故事时，在本目录建 `<feature>.md` 或子目录
- 需求变更时同步更新对应文档，并记录到 `../development-log/`
- 功能行为一旦确定，落为 `../Specification.md`；API 落为 `../API_DOCUMENTATION.md`
- 已取消 / 明确不做的需求，在文档内注明裁决与理由（不静默删除）
