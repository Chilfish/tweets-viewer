# 用户故事

**项目**: Tweets Viewer | **最后更新**: 2026-08-09

---

## US-01: 沉浸式浏览时间线

**作为** 归档作者
**我想要** 在主时间线无限向下滚动加载推文
**以便** 连续、无缝地回顾历史内容

**验收标准**:
- 滚动到底部自动加载下一页并追加到列表末尾
- 只有当 `meta.hasMore` 为 true 且非 Fetching/Error 状态时才加载
- 加载中显示骨架屏/FeedStatus，不打断滚动

## US-02: 精确定位历史内容

**作为** 读者
**我想要** 通过分页器跳转到特定页码
**以便** 快速访问归档的特定部分（如最早的内容）

**验收标准**:
- 分页器显示当前进度 `1 / N`
- 跳转触发列表替换而非追加，滚动位置重置到顶部

## US-03: 按日期范围筛选

**作为** 研究者
**我想要** 选择起始/结束日期筛选推文
**以便** 聚焦特定时间段的内容

**验收标准**:
- DateRangeFilter 支持"草稿模式"，选择不立即生效
- 点"应用"后将 `start`/`end` 写入 URL 并触发硬重载
- 激活后按钮显示具体筛选值（如 "2023/01/01 - 2023/12/31"）

## US-04: 关键词搜索

**作为** 研究者
**我想要** 输入关键词搜索归档推文
**以便** 找到特定主题的内容

**验收标准**:
- 搜索视图 `/search/:name?q=keyword`
- 支持指定用户范围内搜索
- 缺失 `q` 参数返回 400 `{ "error": "keyword is required" }`

## US-05: 浏览媒体墙

**作为** 读者
**我想要** 以网格方式浏览所有含媒体（图片/视频）的推文
**以便** 快速翻阅视觉内容

**验收标准**:
- 媒体墙排除转推
- 瀑布流网格布局，点击查看详情
- 支持分页

## US-06: "那年今日"回顾

**作为** 归档作者
**我想要** 查看历史年份同一天发布的推文
**以便** 回忆往日的今天

**验收标准**:
- `/memo/:name` 路由
- 支持分页与排序方向

## US-07: 浏览 IG 帖子

**作为** 归档作者
**我想要** 浏览关联的 Instagram 帖子
**以便** 在同一平台回顾 IG 内容

**验收标准**:
- `/ins/:name` 路由（:name 为 twitter userName）
- 无限滚动 + 分页器
- 无 IG 数据时优雅降级（`user: null`）

## US-08: 排除回复

**作为** 读者
**我想要** 过滤掉回复推文
**以便** 只看原创内容

**验收标准**:
- `noReplies=true` 参数生效
- 与日期范围/排序筛选可组合

## US-09: 首屏快速加载（SSR）

**作为** 访问者
**我想要** 页面首屏直接渲染内容
**以便** 不用等待客户端 JS 拉取数据

**验收标准**:
- 首屏 SSR（SEO 友好）
- 后续交互纯客户端

## US-10: 排序方向切换

**作为** 研究者
**我想要** 切换时间排序方向（最新优先/最旧优先）
**以便** 从不同时间方向浏览

**验收标准**:
- `reverse` 参数：true 为旧→新，false 为新→旧
- 切换触发硬重载
