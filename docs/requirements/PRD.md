# 产品需求文档 (PRD)

**项目**: Tweets Viewer | **最后更新**: 2026-08-13

---

## 1. 愿景

一个「推文归档阅读器」：数据来自离线归档（PostgreSQL），前端提供沉浸式无限滚动 + 精确分页的阅读体验。**纯只读、无社交交互**——不做发推、点赞、关注。

与直接刷 Twitter 不同，本产品聚焦于**已归档历史内容的连续性阅读**：数据一次性抓取入库，浏览体验不依赖实时网络，是"静态数据的动态阅读器"。

## 2. 用户画像

| 角色 | 特征 | 核心诉求 |
|---|---|---|
| **归档作者（本人）** | 维护 Twitter + Instagram 归档的个人 | 完整回看自己的历史内容，按时间/关键词精确检索 |
| **内容读者** | 对归档内容感兴趣的访问者 | 沉浸式浏览、快速跳转特定时间段、媒体墙翻阅 |
| **研究者/粉丝** | 关注特定账号的内容演变 | 关键词搜索、"那年今日"回顾、按日期范围筛选 |

## 4. 非功能需求

1. **只读性**：系统不提供任何写入功能，数据全部来自离线归档
2. **流动性与定位性并存**：无限滚动提供沉浸感，分页器提供精确控制
3. **SEO 友好**：所有分页/筛选状态反映在 URL 中，支持分享和书签
4. **SSR 首屏**：首屏服务端渲染，后续交互纯客户端（SPA）
5. **响应式**：桌面端（macOS 原生感）+ 移动端（iOS PWA 原生感）
6. **性能**：双层缓存（服务端 LRU + 客户端 axios-cache-interceptor）

## 5. 成功指标

- 归档数据覆盖完整（历史推文 + 媒体 + IG 帖子全部入库）
- 浏览体验流畅：无限滚动无卡顿，分页跳转即时
- 检索精准：关键词/日期范围/排除回复筛选结果正确
- 部署稳定：Vercel + Workers 可用性高，每日同步 cron 不中断
