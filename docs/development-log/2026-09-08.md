# 2026-09-08

## 全量「那年今日」：`/memo` 无用户模式 + Phase 6 废弃

### 背景

- 用户定调：Phase 6（测试纵深 × 数据洞察 × 阅读新体验）**废弃不做了**，`action-plan.md` 里程碑状态改为 ❌。
- 新功能：搜索页已支持不选用户的全库搜索，那年今日的 memo 页也补上「不选用户」的全量模式——分组列出所有归档用户的同月同日回忆。

### 设计决策（Apple 视角）

- **分组轴线 = 按年为主、用户为小节**（两层结构）：
  - 「那年今日」的灵魂是时间而非人，`RitualHeader` 6xl 日期是主角，主分组顺时间走才不背叛仪式语义；
  - 内容优先（Deference）：年分章 + 人小节是轻结构，用户先行会把名字抬到日期之上、N×M 重复分隔视觉噪音大；
  - 复用：单用户 memo 本就是 `YearDivider` 按年分章，全量版延续它；`UserDivider` 从 `search.tsx` 提取共享。
- **数据流复用统一分页流**：`useUrlPaginatedStream` + `InfiniteScrollTrigger`，不新造分页；全量数据量天然小，仍走统一流实现最小、复用最高、超量兜底。
- **ProfileHeader 抑制**：全量 `/memo`（及顺带的全量 `/search`）是跨用户视图，不应显示任何单一用户头——layout 现有 `displayActiveUser = storeActiveUser || loaderActiveUser` 会带出 stale 头，需加 handle 抑制。
