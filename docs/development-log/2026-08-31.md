# 2026-08-31

## web-react apiUrl 改为从环境变量获取（去硬编码）

此前 `packages/shared/constant.ts` 的 `apiUrl` 走「preview/dev/prod 环境判定」的硬编码分支。本次改为从环境变量读取，配置源收敛到 `env.server.ts`。

- **`env.server.ts`**：schema 新增 `API_URL`（`z.url()`，默认 `https://tweet-api.chilfish.top`），并在 `getPublicEnv()` 中公开（非敏感）。注：为避免前端构建被 DB 凭据绑定，未让 `vite.config.ts` 引入完整校验后的 `env` 对象。
- **`vite.config.ts`**（注入枢纽）：用 Vite `loadEnv` 读取仓库根 `.env`（或进程环境）的 `API_URL`（dev 模式保持 `localhost:3000` 反代本地 API），经 `define['import.meta.env.VITE_API_URL']` 注入客户端/SSR bundle，同时作为 `/api` 反向代理 target。前端从此不再写死 apiUrl，改由 `.env` / 平台环境变量（如 Vercel）配置。
- **`packages/shared/constant.ts`**：`apiUrl` 读取优先级 = `import.meta.env.VITE_API_URL`（Vite 注入）→ `process.env.API_URL`（非 Vite/Node 上下文）→ 旧的 preview/dev/prod 回退（storybook/vitest 等未注入环境保持原行为）。

验证：web-react typecheck ✅ build ✅（client/server bundle 均已内联 `https://tweet-api.chilfish.top`，非硬编码路径）；shared 20 tests ✅；`loadEnv` 确认能读取 `process.env.API_URL` 与仓库根 `.env` 的 `API_URL`。
