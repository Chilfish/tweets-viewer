# 2026-09-13

## 工程规范对标：文档体系 + 门禁约束

参照姊妹项目 anonTweet 的文档与工程规范，对本仓库做一次系统性对齐，目标是把「口头约定」变成「可执行、可追溯」的约束。

### 约束（可执行层）

- **NODE_ENV 固定**：引入 `cross-env`，`apps/web-react` / `apps/server` / `packages/database` / `packages/shared` 的 `test` / `dev` / `build` 脚本全部固定 `NODE_ENV`。修复宿主 `NODE_ENV=production` 泄漏进 Vitest 导致 React 加载 production 构建（`React.act` 缺失 → web-react 22 个组件用例全红）；同时发现脚本内联 `NODE_ENV=test cmd` 在 Bun shell 下静默无效。沉淀 [postmortem 005](../postmortem/005-host-node-env-leak.md)。
- **根脚本聚合**：新增 `lint:check`（`--max-warnings=0`）、`typecheck`、`test`（四包串行）、`test:visual`；`dev:*` / `build:client` / `deploy` 统一为隐式 `bun --cwd <dir> <script>`（遵守 postmortem 004）。
- **pre-push 真实门禁**：`lefthook.yml` 由单一 `build:client` 升级为 `lint:check + typecheck + test + build:client`。
- **断言存在性 lint**：`eslint.config.mjs` 启用 `test/expect-expect` / `test/no-conditional-expect` / `test/no-standalone-expect`；忽略 `.commandcode/**`（工具产物）修复 lint 假红。
- **依赖补齐**：`bun install` 恢复缺失的 `@vitest/browser-playwright`（web-react Vitest 配置加载必需）。
