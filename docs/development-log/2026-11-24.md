## 归档 API 的 Agent Skill 重构：入口从 PowerShell 换成 TypeScript

原 skill 用 550 行 pwsh 封装，参数解析、HTTP 请求和终端渲染混在一个文件里，读起来成本高；文档也停在旧行为（`medias` 日期可单边、IG 分页无游标、`users.location` 类型）。这次按 Agent Skills 规范重写文档，并把入口改成单文件 TypeScript。

### 脚本

- 删除 `scripts/tweets-viewer.ps1`，新增 `scripts/tweets-viewer.ts`，Bun 直接运行，零第三方依赖。
- 保留 11 个命令与 `--json`；参数校验前置（`name` / `q` / `page` / `size` / `cursor` / 日期 / 布尔值），错误带字段名。
- 修正旧实现的问题：`--reverse=false` 被当成 true；`users.location` 是对象却按字符串打印；`--cursor` 与 `--page` 同时给时静默由服务端取舍。
- 输出约定：JST 渲染、HTML 实体解码、视频 MP4 变体链接、stdout/stderr 分离、仅 TTY 加颜色。

### 文档

- `SKILL.md` 按 skill-builder 的结构重写：何时使用 / 启动方式 / 命令表 / 参数规则 / 分页 / 输出 / 排错 / 维护。
- 新增 `references/data-shapes.md`，把长类型定义从正文拆出去，保留渐进披露。
- 对照 `apps/server/routes/*.ts` 修正事实：`medias` 的 `start` / `end` 必须成对才生效、IG 固定每页 15 条且无游标、「那年今日」按北京时间判定当天、未归档用户在单资源端点返回 404、集合端点返回 200 + 空数组。
- `docs/INDEX.md` 增加 Agent 工具入口。

### 验证

- 实跑 `tweets` / `medias` / `search` / `today` / `today-all` / `stats` / `users` / `user` / `ins` / `image` / `status`，以及错误分支（非法 name、单边日期、cursor + page、404）✅
- `medias` 带日期范围与 `ins --page 2` 的 `meta` 均符合文档 ✅
- `image --out` 落盘成功，自动创建父目录 ✅
